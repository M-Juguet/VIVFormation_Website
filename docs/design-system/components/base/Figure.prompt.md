**Props** — `caption` dit ce qu'il faut regarder, pas ce qu'on voit déjà. `credit` pour l'auteur ou la provenance. `ai` affiche « Image générée avec <outil> » : obligatoire sur tout visuel produit ou retouché par une IA. `frame={false}` pour une image à fond perdu. `placeholder` en maquette.

**À faire** — Captures prises sur les fichiers d'exercice de VIV Formation, jamais sur un projet client ou l'écran d'un participant, dans le thème sombre du logiciel.

**À éviter** — Ombre portée, perspective, biseau. Photo de banque mise en scène. Toute image prise en session.
