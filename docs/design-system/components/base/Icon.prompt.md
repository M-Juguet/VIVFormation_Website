Icône Lucide au format du système : grille 24, trait 2, bouts et jointures arrondis, encre héritée du texte.

    <Icon name="clock" size={20} />
    <Icon name="outil-blender" size={24} tile="degrade" shape="carre" label="Blender" />

**Props** — `name` parmi les 30 tracés embarqués ; `path` pour tout autre SVG Lucide. `size` : 20 dans l'interface, 24 dans les documents et les pastilles. `tile` : pastille pleine (`degrade`, `rose`, `gold`, `action`, `ink`), 1,6 × l'icône, `shape` cercle ou carré. `label` rend l'icône signifiante ; sans lui elle est décorative.

**À faire** — Les repères d'outil (`outil-*`) sont des marqueurs neutres, jamais les logos des éditeurs. Gardez la même icône pour un domaine donné dans tout le catalogue.

**À éviter** — Une icône seule pour signaler un statut. Mélanger deux jeux d'icônes sur un même support. Redessiner un tracé à la main. Un trait sous 1,5.
