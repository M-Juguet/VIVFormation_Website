Étiquette courte qui qualifie une formation ou une session : outil, modalité, statut d'organisation.

    <Badge tone="rose">Blender</Badge>
    <Badge tone="success" icon={<Icon name="circle-check" size={16} />}>Session confirmée</Badge>

**Tonalités** — `rose`, `peach`, `gold` (tags outil et domaine, texte `ink-on-pastel`), `neutral` (modalité), `success` / `warning` / `danger` / `info` (statuts).

**À faire** — Ordre invariable sur une carte : tags outil, modalité, statut. Statuts autorisés : « Dates à convenir », « Session confirmée », « Session reportée ».

**À éviter** — La couleur seule pour signaler un statut : le mot reste obligatoire. Les mentions qui n'existent pas chez VIV Formation : CPF, distanciel, Qualiopi, places restantes.
