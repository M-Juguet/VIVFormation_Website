Affiche un raccourci clavier dans une phrase, un livret ou une fiche mémo, en kbd sur surface-code.

    Pressez <Kbd keys={['Shift', 'A']} /> pour ouvrir le menu d'ajout.

**À faire** — Touches dans l'ordre de pression. Chemins de menu et noms de nœuds en `code`, raccourcis en `Kbd`.

**À éviter** — Le gras dans le texte courant pour signaler une touche.
